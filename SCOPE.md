# Scope (MVP)

## In scope (must build)
- Login with **pre-created demo accounts** (email/password).
- Community selection (minimum **2 seeded communities**).
- Weekly phase shown and enforced: `voting | discussion | closed`.
- For each community/week: **3–5** scientific texts/articles:
  - title + short summary + link
- Voting:
  - **1 vote per user**
  - only allowed in `voting`
  - results update **realtime** across clients
- Discussion:
  - only allowed in `discussion`
  - comments update **realtime** across clients
- Admin screen:
  - switch the phase (`voting/discussion/closed`) for a community

## Out of scope (must NOT build)
- Community creation / invite / join flows
- Followers, personal feeds, DMs, notifications
- Recommendation algorithms
- Advanced moderation, reporting, or complex role systems
- “Full social media” features beyond the weekly flow
